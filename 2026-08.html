Microsoft Copilot 新功能速览 | 2026 年 8 月

作者：Daniel Vargas（Microsoft）· 发布日期：2026 年 8 月 31 日 · 查看英文原文

本文为 Microsoft Copilot 官方月度更新（2026 年 8 月刊）的中文整理版。本月更新覆盖 Cowork、Copilot Chat、Notebooks、Teams、Word、PowerPoint、Excel、SharePoint、Outlook、OneDrive 和 Planner，并带来新的连接器、插件与 IT 管理能力，帮助用户在日常应用中更高效地完成工作。

面向用户的能力

Cowork：更灵活地控制工作强度与额度消耗

  • 选择工作强度8 月已推出
    用户现在可以在 Cowork 的撰写框中同时选择模型与工作强度，在回答质量、处理速度和 Copilot Credits 消耗之间取得平衡。「中等」是适合日常工作的默认选项；「轻量」适合简单任务；「高」「超高」和「最大」则会投入更多时间进行分析与推理，适合更复杂的工作，但处理速度可能更慢，也会更快消耗可用额度。
  • /cost 技能8 月已推出
    新增的 /cost 技能可显示当前任务会话的预计额度消耗、当月剩余额度百分比、本月至今的使用量，以及每月额度重置日期，帮助用户在执行工作时及时掌握成本。
  • 「Scheduled」更名为「Automations」8 月已推出
    Cowork 中原有的「Scheduled」选项卡现已更名为「Automations（自动化）」，并把定时任务与事件触发式任务集中在同一处，方便用户统一查看和管理自动运行的工作。

Copilot Chat：文本选择、会话分享等更新

  • 仅针对选中的文本继续操作8 月已推出
    用户可以在 Copilot 回复中选中一个句子、一段文字或一张表格，再要求 Copilot 只对所选内容执行后续操作。被选中的内容会显示在提示词输入区域中，让指令范围更加明确，减少重复描述上下文的需要。
  • 分享完整会话或单条回复8 月已推出
    用户可以通过页面右上角「共享」菜单中的「Share chat」分享完整聊天，也可以从某条回复的「更多选项」菜单中选择「Share response」只分享该条回复。接收者会获得只读副本，同时可以把内容延续为自己的新对话。
  • 基于 Power BI 数据进行推理6 月公开预览，8 月全球推出
    Copilot Chat 与 Cowork 现在可以在用户已有权限范围内，对 Power BI 报表和语义模型中的企业数据进行推理，把受治理的业务指标直接带入分析与问答流程。
  • 模型驱动的答案卡片8 月已推出
    在受支持的 Microsoft Entra 帐户和 Microsoft 帐户体验中，Copilot 可以根据问题呈现更丰富的答案卡片，覆盖天气、体育、财经、图片、视频、地点和新闻等信息类型，让用户更快获得结构化结果。
  • 使用「Try again」重新生成回答8 月已推出
    用户可以通过「Try again（重试）」重新生成最近一次回答，既可以继续使用原模型，也可以切换到其他模型后再次作答，便于比较不同模型的结果。
  • 在移动端起草 Outlook 邮件8 月已推出
    移动端用户可以直接在 Copilot Chat 中描述要发送的邮件，Copilot 会生成一封内嵌的 Outlook 草稿；用户随后可在 Outlook 移动应用中打开草稿，继续编辑并发送。

Copilot Notebooks：新的使用方式

  • Copilot 应用与 OneNote 中的同步体验8 月已推出
    Copilot Notebooks 现在提供两种保持同步的使用方式：在 Copilot 应用中进行轻量级聊天、管理引用源并创建产出物；在 OneNote 中开展更深入的项目工作、创建更多类型的产出物并与他人协作。点击「Open in OneNote」即可直接进入同一个已同步笔记本。
  • 推荐更贴合项目的产出物8 月已推出
    Notebooks 会结合 Work IQ 与笔记本已有内容推荐适合创建的产出物，并可据此生成更具体、更符合当前项目上下文的 Word 文档、Excel 工作簿或 PowerPoint 演示文稿。
  • Android 多模态捕捉9 月推出
    Android 端将支持同时记录音频、图像和笔记，并把这些输入整理为结构化的笔记本笔记。该能力也可通过 iOS 和 iPad 版 OneNote 使用。

Teams 中的 Copilot：切换会议回顾语言

8 月已推出Teams 会议回顾新增语言切换控件，用户可以在会议回顾已经生成后，将其转换为其他语言，无需重新生成整场回顾。

Word 中的 Copilot：超链接、图像理解与精细高亮

  • 直接插入并设置超链接格式8 月已推出
    Copilot 现在可以按照用户要求，在 Word 文档中直接插入超链接并完成格式设置，减少手动查找位置、粘贴网址和调整样式的步骤。
  • 理解引用文档中的图像8 月已推出
    Copilot 可以理解所引用文档中的图像，并在生成内容时综合利用相关文字与视觉信息，让基于参考材料起草的结果更加完整。
  • 仅高亮实际改写的文字8 月全球推出
    Copilot 执行改写后，现在只会高亮具体发生变化的单词，而不再高亮整段文字，便于用户快速识别、检查和接受修改。

PowerPoint 中的 Copilot：品牌管控与协作增强

  • 在批注中通知相关人员并分配任务8 月已推出
    Copilot 可以直接在 PowerPoint 批注串中通知相关人员，并把后续事项分配为任务，让团队更快地从反馈转入执行，同时减少在不同工具之间切换和手动跟踪的工作。
  • 严格遵循品牌模板8 月已推出
    启用严格品牌遵循后，Copilot 只会使用组织批准的模板和幻灯片母版版式，不会新增或删除占位符，也不会自行创造版式。该模式适合正式对外、受监管或对品牌一致性要求较高的演示文稿。
  • 通过备注引导生成8 月已推出
    模板设计者可以在幻灯片备注中写入可复用的自然语言生成说明。此后，只要 Copilot 使用该模板创建演示文稿，就会读取这些备注并遵循其中的内容和版式指导。
  • 管理个人自定义技能8 月已推出
    用户可以上传、创建、编辑和删除个人自定义技能，把重复使用的 PowerPoint 指导整理为可复用能力，并在后续演示文稿工作流中随时调用。
  • 翻译体验移入 Copilot8 月已推出
    PowerPoint 的翻译能力从功能区移入 Copilot，翻译处理速度更快，同时文本框可以根据译文长度动态调整大小，减少翻译后的手动排版。
  • 编辑 SmartArt、图表与形状8 月已在 Frontier 推出
    Copilot 现在可以直接编辑画布上的 SmartArt、图表和形状，并在调整内容的同时维持演示文稿的品牌风格。

Excel 中的 Copilot：更改历史技能与聊天历史

  • 更改历史技能8 月已推出
    新的更改历史技能可以总结工作簿近期发生的变化、识别编辑者，并解释由用户或 AI 完成的修改。用户还可以让 Copilot 撤销某项编辑、恢复公式，或把工作簿还原到较早的可用状态。
  • 聊天历史8 月已推出
    Excel 中的 Copilot 现在会保留之前的对话与会话。用户可以从 Copilot 窗格左上角菜单打开聊天历史，并按最近使用顺序继续查看或处理先前的工作。

SharePoint 中的 Copilot：个人技能

8 月公开预览，12 月全球推出用户可以创建能在不同 SharePoint 站点和 OneDrive 中使用的个人技能。每项技能都会以 Markdown 文件的形式保存在用户 OneDrive 中，便于个人维护、更新和复用自己的工作指导。

Outlook 中的 Copilot：代理、邮件与管理增强

  • 直接使用自定义引擎代理8 月已推出
    用户现在可以直接在 Outlook 中访问自定义引擎代理，把组织构建的专属代理能力带入邮件和日历工作流。
  • 通过自然语言管理邮件与日历8 月已推出
    用户可以通过对话让 Copilot 整理邮件、应用类别、创建文件夹、管理收件箱规则，并处理会议和日历事件，减少重复的手动管理操作。

OneDrive 中的 Copilot：文件处理能力提升

8 月公开预览，12 月全球推出Copilot in OneDrive 现在可以查找和分析文件，基于文件内容创建摘要、仪表板和演示文稿，并在不离开 OneDrive 的情况下保存或分享结果，让从检索资料到形成交付物的流程更加连贯。

Planner 中的 Copilot：状态报告与任务增强

  • 生成项目状态报告8 月已在 Frontier 推出
    Planner Agent 可以生成涵盖项目进展、风险、总体状态和下一步工作的状态报告。用户能够指定受众、语气、篇幅以及要包含的章节，让报告更贴合不同汇报场景。
  • 创建并查询 Planner 任务9 月推出
    Copilot 将支持直接创建 Planner 任务，并通过自然语言查询 Planner 中的任务信息，让用户更方便地跟踪和推进工作。

新的连接器与插件

新的连接器与插件进一步扩展了 Copilot 可安全访问的业务系统和行业知识，让用户能够在遵循组织既有权限、合规与安全策略的前提下，检索信息、开展推理并采取行动。本月新增内容包括：

面向 IT 管理员的能力

数据导出与 GitHub Copilot AI Credits

  • 导出 Copilot 与 Agent 365 仪表板数据9 月推出
    Copilot 仪表板和 Agent 365 仪表板将支持导出去标识化的行级指标与属性，用于构建自定义报表。管理员可以获得组织级和用户交互层面的洞察，同时移除个人身份信息。
  • Insights 中支持 GitHub Copilot AI Credit7 月已推出
    Insights 的 Consumption Dashboard 现在支持 GitHub Copilot AI Credit 使用情况。经理、Insights 分析师和全局管理员可以分析额度消耗，并将实际支出与预算进行比较，以便更好地掌握和管理 AI 使用成本。
